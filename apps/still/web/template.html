Still App（1 枚絵）

AI が描いた「ドット絵風の 1 枚絵」を、決まった色数・格子の本物のドット絵にそろえます。

ドットのマス目を見つけて 1 ドット＝1 画素にし、いちばん多い色でマスを塗り、決まった色数のパレットにそろえます。 透明な所は黒で埋めます。出力は正方形のドットです（98 の縦長のドットは再現しません）。ディザは使いません。

① 画像を選ぶ（PNG・JPEG。ここにドラッグしても OK。HEIC は読めません）
（変更あり） 項目の値の組み合わせです（CLI の --mode）。決まりではないので、下の「必要なときに開く」で 1 つずつ変えられます。変えると「（変更あり）」と出て、JSON に変えた項目が残ります。「今風」は最近のインディーゲームの背景のようなドット絵の手直しの出発点で、32 色・4096 色に丸めない・1920×1080 まで・似た色をまとめる です。「写真の下書き」は自分で撮った写真を、塗り直しの出発点になる色を塗り分けた下絵にします（写真の向きを直す・マス目は探さずに横 320 マス・色の塊をまとめる（中）・減色は今風と同じ・孤立したドットをそろえる）
必要なときに開く（変更あり）工程の順: 向き・マス目・色の塊・減色・似た色・孤立したドット・模様・輪郭・余白
写真に記録された向き（EXIF）を見て、正しい向きに回してから読みます。写真の下書きでは初めから入（CLI の --orient・--no-orient）
「マス目を探す」は AI が描いたドットのマス目を自動で見つけます（98・今風の初めの設定。CLI の --grid）。「横のマス数で分ける」はマス目を探さずに、横を決まった数のマスに分けます（縦は縦横の比から。写真の下書きの初めの設定。CLI の --width）
「横のマス数で分ける」のときのマスの数です（CLI の --width）
大きさの上限 × ドット数（幅×高さ）。超えたら出力せずに、収まる「横のマス数」の候補を出します。CLI の --max-size
境目は残したまま、似た色の近所をならして色の塊にします（桑原フィルタ）。強いほど塊が大きく、細かい所が消えます。作業用に 1 マスを 4×4 の画素に縮めてから まとめます。写真の下書きでは初めから「中」、ほかは「しない」（CLI の --smooth off・weak・medium・strong）
パレットの色を RGB 各 16 段階（4 ビット）の 4096 色の中から選びます。98 の初めの設定で入（CLI の --4bit・--no-4bit）
パレットの 1 色を絵の中のいちばん暗い色にして、暗い線が中間の色に吸われて消えないようにします（CLI の --keep-darkest・--no-keep-darkest）
減色のあと、見た目でほぼ区別できない色どうし（OKLab の距離 0.04 未満）を、ドット数の多い方の色に合わせます。いちばん暗い色は残します。色数は上限なので、少なくなることがあります。今風・写真の下書きの初めの設定で入（CLI の --merge-similar・--no-merge-similar）
まわりの 8 ドットに同じ色が 1 つも無く、まわりの 7 つ以上が同じ色のドットを、その色にします（AI のにじみの点を消すため）。いちばん暗い色のドットと絵の端のドットは変えません。1 回だけ通します。写真の下書きの初めの設定で入（CLI の --tidy-dots・--no-tidy-dots）
AI が描いたディザ風の所は、減色するとばらばらの点になります。そういう所を、その場所の多い 2 色だけを使った 2×2 の決まった模様（濃さ 5 段。50% は市松）に置き換えます。輪郭・平塗りの面・小さい所・3 色目が多い所は変えません（CLI の --tidy-pattern）
明るさの差が大きい色の境目に、暗い方の側へ 1 ドットの線を引きます。線の色はパレットのいちばん暗い色で、新しい色は作りません（CLI の --outline）
余白（キャンバス） × 空ならなし。入れると、絵を真ん中に置いて余白を足し、この大きさにします。余白はパレットのいちばん暗い色。CLI の --canvas
