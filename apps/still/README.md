# Still App（1 枚絵）の使い方

AI が「PC-98 のゲーム CG 風」などに描いた **ドット絵風の 1 枚絵**（背景も絵の一部）を、本物のドット絵
（1 ドット＝1 画素・決まった色数・ディザなし）にそろえる。98 の条件に全部従わせるのではなく「98 風」を目指す。
ブラウザ版と CLI は同じ Python のコード（`retrocore/still/`。グリッド検出と色の選び方は Sprite App の `retrocore/sprite/` を使う）で動き、
同じ設定なら PNG と JSON はバイト単位で同じ。オプションと JSON の形は [docs/cli.md](../../docs/cli.md#1-枚絵still-app) の「1 枚絵（Still App）」。

## ブラウザ版

1. GitHub で `apps/still/web/still-app.html` を開き、右上の「Download raw file」を押す
2. ダウンロードした `still-app.html` をダブルクリックして、ブラウザ（Chrome・Edge など）で開く
3. 「準備ができました」と出たら（初回は 10〜30 秒）、画像（PNG・JPG）を選ぶ → 変換 → 「PNG を保存」「JSON を保存」

- 元の絵と結果を横に並べて見られる（拡大はニアレストネイバーで、倍率を選べる）。パレットの色見本も出る
- 色数・横のマス数・大きさの上限・キャンバス・4096 色に丸める・いちばん暗い色を取っておく は「必要なときに開く」の中
  （初めの設定から変えると、見出しに赤で「（変更あり）」）。説明の文は「？」で出す
- 「必要なときに開く」の「ざらついた範囲を模様に整える」に印を付けると、ディザ風の所を 2 色の決まった模様に整える（CLI の `--tidy-pattern`）。
  変換した後は「整えた範囲を色で重ねる」で、整えた範囲を薄い色（縁は濃い色）で結果に重ねて見られる（表示だけで、保存する PNG は変わらない）
- マス目が見つからないとき・大きさの上限を超えたときは、横のマス数の候補のボタンが出る（押すとその数で変換する）
- いちばん下に Pyodide の版とビルド番号が出る

## CLI

```bash
python -m apps.still 入力.png --mode pc98 --out out/still/部屋      # → 部屋.png（インデックスカラー）と 部屋.json
python -m apps.still 入力.png --width 160                           # マス目を探さずに、横 160 マスに縮める
python -m apps.still 入力.png --colors 8 --canvas 640x400          # 8 色、余白を足して 640×400 に
python -m apps.still 入力.png --width 600 --tidy-pattern            # ざらついた範囲を 2 色の模様に整える
```

`--mode pc98`（既定）は初めの設定の組み合わせ（16 色・4096 色に丸める・大きさの上限 640×400・いちばん暗い色を取っておく）で、
`--colors`・`--no-4bit`・`--max-size`・`--width`・`--canvas`・`--no-keep-darkest` で個別に変えられる。

## 知っておくこと

- **出力は正方形のドット**。PC-98 の画面のドットは少し縦長（約 1：1.2）だが、それは再現しない
- 透明な所は黒で埋める（背景も絵の一部として扱う）
- 減色ではディザは使わない。ただし `--tidy-pattern`（既定は切）では、AI がディザ風に描いて減色でばらばらの点になった所だけを、
  パレットの 2 色の 2×2 の決まった模様（濃さ 5 段。50% は市松）に置き換える。輪郭・平塗りの面・小さい所・3 色目（描き込み）が多い所は変えない。
  比較の画像は `python tools/compare_still_pattern.py 入力.png --width 600 --out out/still/比較 --crop 左,上,右,下`
- 大きな絵のドットの手直しは、Pixelorama などのドット絵のソフトで行う想定
- マス目が見つからないとき・大きさが上限を超えるときは、出力せずに止めて `--width` の候補を出す
