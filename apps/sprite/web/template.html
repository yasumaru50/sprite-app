Sprite App（ブラウザ版）

ドット絵風の画像（AI が描いたドット絵など）を、1 ドット＝1 画素のスプライトに直します。 画像はこのパソコンの中だけで処理され、どこにも送られません。

① 変換したい画像を選ぶ（ここに画像をドラッグしても選べます。「コマが並んだ絵」では何枚でも選べます）

つなげるファイル

長い動き（ダンスなど）を AI に何枚かに分けて描かせたときは、ファイルを全部選ぶと、上から順につなげて 1 つの動きにします （1 枚の中のコマは 1 つでも何コマでもかまいません）。▲▼ で並び順を入れ替え、「外す」で一覧から外せます。変えたら「② 変換する」をもう一度押します。 ドットの大きさはファイルごとに見つけ、色（パレット）は全部のファイルで 1 つにします。つなぎ目のコマは自動では混ぜません。 CLI では python -m apps.sprite dance1.png dance2.png --frames --join。

    動きごとの設定

    順番は、その動きの中での番号です（その動きのファイルの左のコマから 1, 2, …。例 1,2,3,2 や 1,2,3,2r）。 順番・時間・くり返すかは変えるとすぐ作り直します。縦のそろえ方と上げ下げは「② 変換する」をもう一度押すと変わります。

    再生の順番と時間

    変えるとすぐ作り直します。変換はやり直しません。
    左のコマから 1, 2, … 。空なら左から順。同じコマを何度使っても OK（例 1,2,3,2）。 番号の後に r を付けると、そのコマを左右に裏返して使います（例 1,2,3,2r。回る動きなど。キャラは横にずれません）
    保存するファイルの名前に入ります（walk・run など。半角英数字）

    動き

    「表で編集」は、選んでいる動き（呼吸など）を、フレームごとの数の表にして細かく直せます（慣れてから使う機能です）。
    動きを選ぶと、変換結果から動きを作って再生し、スプライトシート（PNG と JSON）を保存できます。 「なし」のときは変換結果の 1 枚の PNG（③）だけです。

    重ね（エフェクト）

    変換の設定

    元の絵のドット 1 個が何画素か（小数も可。例 6.5）。空なら自動（CLI の --dot-size）。 自動で見つからないときは候補が出ます。つなげる・まとめるときは全部のファイルに同じ大きさを使います
    余計なドットを片付ける強さ
    キャラクターの外側の輪郭（「細く」は、コマの絵などで 2 ドットの太さになった外側の輪郭を 1 ドットにします）

    コマの切り分けとそろえ方（コマが並んだ絵）

    変えたら「② 変換する」をもう一度押します。
    絵に並んでいるコマの数。空なら自動で数えます（数が違えば作らずに知らせます）
    コマごとの左右の位置を、何に合わせるか
    歩きは「足元」、足が地面から離れる走り・跳びは「頭の高さ」、ジャンプで宙に浮くコマがあるときは「元の絵の高さを保つ」
    元のコマごとに、そろえた位置から何ドット上げる・下げるか（− が上）。数は元のコマの数と同じ。空ならなし。 ジャンプの高さが自動でうまく出ないときに使います（CLI の --frame-shift-y）。−256〜256 ドット（シートはそのぶん広がります）。 直したドットがあっても、上げ下げ・そろえ方だけを変えたときは、キャラの同じ所に付け直します

    動かす範囲（1 枚の絵の動き）

    下から何ドット目か（1 = いちばん下の行）
    帯・四角の範囲は「表で編集」の中で描きます（表を開いたときに出ます）。
    左右反転のシートには設定がありません（コマが並んだ絵ではいつも作ります）。保存は下の「まとめて保存（ZIP）」か「1 つずつ保存」で。
    細かい設定（変更あり）体の上下／ちらつき／1 コマ目と同じにする範囲／小さな部品を守る
    走りで体ごと跳ねて見せるとき。− が上（ドット）。数は順番の数と同じ。 「あり（0,-1,0,-1）」は 2・4… コマ目で、「あり（-1,0,-1,0）」は 1・3… コマ目で 1 ドット上がります
    「あり」は、上の方（頭のあたり）で 1 コマ目と違う小さな点・短い線だけを 1 コマ目の色に戻します（腕・脚・目や口の形の違いは戻しません）
    ちらつきの見える化（PNG） ちらつきの記録（JSON）
    ちらつきの見える化は、上の方（頭のあたり）で 1 コマ目と違うドットを赤紫の枠で囲んだ画像です（自動では直しません。手直しの目印にしてください）。変換すると作ります。
    縮める・伸ばすときに、目・頬など（同じ色の塊で縦 3 ドット以下）の長さを変えない（CLI の --keep-small-parts）

    1 コマ目と同じにする範囲

    頭など。変えるとすぐ写し直します。変換はやり直しません。 下の 1 コマ目の上をマウスでドラッグすると、四角い範囲を描けます（何個でも足せます）。2 コマ目以降で、 範囲の中身がいちばんよく合う位置（上下左右「位置を探す幅」ドット以内）を探し、そこに 1 コマ目のドットをそのまま写します。 目・口は 1 コマ目とまったく同じになるか、そのコマのままです（混ざりません）。合い方が低い・境目で段差や輪郭の途切れができる・ 目や口に腕などが入ってくるコマは写さずに理由を出します。写した結果は、そのまま再生と保存（シート・JSON・GIF・反転・.piskel）に入ります。

        ドットを直す
        
        
        ちらつき・ゴミ・輪郭を数ドット直す所です（大きな描き直しは Piskel で）。
          コマごとにドットを塗る・消すと、そのまま再生と保存（シート・JSON・GIF・左右反転・.piskel）に入ります。
          直しは元のコマに入るので、順番 1,2,3,2 の 2 番目と 4 番目は 1 回直せば両方変わります。使える色はシートのパレットだけです（新しい色は作れません）。
          順番に r（裏返したコマ。例 2r）があると、「次のコマ」で裏返したコマも開けます。元のコマの直しは裏返したコマにも裏返して付き、
          裏返したコマで直したドットは裏返したコマだけに入ります（リボンなど、左右で違う物が反対側に移るのを直すとき）。
          上の「1 コマ目と同じにする範囲」や変換の設定を変えても、直しはその上に重ね直します（下の色が変わったドットは数を知らせます）。
        
        
        
          
          
          
          
          
          
        
        
        
        
          
          
          
          
          
            
            
          
          
          
        
        
        
        
        
        マウス: 左ドラッグ = 描く（ペン・消しゴム）／右クリック・右ドラッグ = 消しゴム／Alt＋クリック = スポイト（色を拾ってペンに戻る）。
          キー（カーソルが絵の上にあるとき・この欄を選んでいるとき）: B ペン／E 消しゴム／I スポイト／「,」「.」前後のコマ／O 前のコマを薄く重ねる・やめる／
          Ctrl＋Z 元に戻す／Ctrl＋Y か Ctrl＋Shift＋Z やり直し。元に戻すは 1 回のドラッグを 1 つと数えて 50 回まで。前のコマの重ね（再生の順番で 1 つ前。1 コマ目は最後のコマ）は見るためだけで、保存には入りません。
          「重ねるコマ」で 2 つ前・1 コマ目・番号で選んだコマにもできます。歩き・走りは 1 と 3、2 と 4 が同じ足の形になることが多いので「2 つ前」が向いています
          （前が無いときは最後から数えて戻ります。動きをまとめているときは同じ動きの中で数えます。今のコマと同じになるときは重ねません）。
        
        
        
          
        
        
        
        「差し替えを描く」: 1 コマ目が出るので、目を閉じた形に描き直してください（使える色はシートのパレットだけ）。
          1 コマ目と違うドットだけが「差し替え」になり、範囲（違うドットを囲む四角）は自動で決まります。動きの中に 1 回まばたきが入り、
          2 コマ目以降は頭の位置を上下左右 3 ドット以内で探して当てます（合わないコマには入れずに知らせます）。
          「半分閉じた目」も描くと、開く → 半分 → 閉じる → 半分 → 開く になります。まばたきがかかるコマは時間で分けます（全体の時間は変わりません）。
          動き 1 周がまばたきの間隔より短いときは、動きを何周か繰り返したシートにして、その中に 1 回だけ入れます。
          シート・JSON（swaps）・GIF・左右反転・.piskel に入ります。差し替えを描かなければ、出力は差し替えの無いときと同じです。
          口パク: 「描く絵」で「開いた口」を選んで口を開けた形に描くと、ふつうのシートとは別に「しゃべりのシート」ができます
          （今の動きの上で 閉じる → 開く をくり返します。「半分開いた口」も描くと 閉じる → 半分 → 開く → 半分。閉じた口は 1 コマ目のまま）。
          まばたきも入ります（目と口の四角が重なるコマには、口を優先してまばたきを入れません）。口が入らないコマが半分以上なら作りません。

      直したドットはそのまま使って、JSON・GIF・左右反転のシート・横 1 列に並べ直したシートを作り直します。
      新しい色・半透明のドットなどがあれば知らせて、場所の画像を出します（勝手には直しません）。変換の準備（上の Python の読み込み）ができてから使えます。
        
    
        
      
        
        
        
        Piskel の Save → Save offline as File の .piskel か、Export → PNG で書き出したシート
        
      
        
      
        
        
        
        シートと一緒に保存した JSON（ZIP の中のものか、「1 つずつ保存」の ⑤ で保存したもの）
        
      
        
      
        
        
        
        選ぶと、直したドットに印を付けた画像も作ります（前の版の JSON では、色を比べるのにも使います）。
          動きをまとめたシートのときは要ります（ほかの動きのコマはここから使います）
        
      
        
      
        
        
        
        直したファイルの名前（<出力名>_walk.piskel など）から決めます。分からないときは選んでください
      
        
    
        
    
        
      
        
        
        
        シートには再生する順に 1 コマずつ並んでいます。直した結果が違えば知らせます
      
        
      
        
        
        元のパレットに無い色をいちばん近い元の色に、半透明を透明か不透明にします（ふだんは切）
      
        
      
        
        
        
      
        
    
        
    
        
    
        
    
        
    
        
    
        
      
        
      
        
        
        
        
        
      
        
      
        
      
        読み方のメモ
          
      
          
      
          ファイルの中身は CLI の --readback と同じです。
          
    
          
  
          
    
          
  
          

  
          
    大きさをくらべる変換した素材を足元をそろえて並べ、大きさ・線の太さを 1 枚の画像で確かめる
    
          
    
          大きさをくらべる
          
    
          AI は絵ごとに格子の細かさを決めるので、変換した素材どうしの大きさや線の太さがそろっているかを確かめます。
      透明な余白を切り詰め、足元を同じ地面の線（赤）にそろえて、同じ倍率で横に並べます（絵そのものは拡大・縮小しません）。
      マス目は地面の線から数えるので、高さが何マス分か読めます。シートの PNG は、同じ名前の JSON も選ぶと 1 コマ目だけを使います。
          
    
          1 枚目に主人公などの基準のキャラを置くと、その頭の高さに青い点線が引かれ、ほかの絵と比べやすくなります。
          
    
          
      
          
        
        
        選んだ順に一覧の最後に足します。上の作業とは別です
      
          
      
          
        
        
        
      
          
      
          
        
        
        
      
          
    
          
    
            
    
            
      
      
      くらべた画像を保存（compare.png）
    
            
    
            ファイルを選ぶか「今の結果を足す」を押してください。
            
    
            
    
            
    
            
      
            
      
              
      
              画像は CLI の compare と同じです。
