# スプライトを Piskel で手直しする（初心者向け）

Sprite App で作ったシートを、ブラウザで動くドット絵エディタ **Piskel**（https://www.piskelapp.com/ 。インストール不要）で直し、
Sprite App に読み戻して JSON・GIF などを作り直す手順です。自動の変換は完璧ではないので、目・輪郭・ちらつくドットなどを最後に手で直す前提です。

## 小さな直しはアプリ内、大きな描き直しは Piskel

| 直したいもの | おすすめ |
| --- | --- |
| 数ドットのちらつき・ゴミ・穴、外側の輪郭を 1 ドット細くする | **Sprite App の中**（ブラウザ版の「コマの再生と保存」の「**ドットを直す**」） |
| 目・口の描き直し、腕・髪の形を変える、レイヤーを使う、新しい色を使う | **Piskel**（下の ①〜⑤） |

**アプリ内の「ドットを直す」**（Piskel を開かなくてよい）:

1. 「コマが並んだ絵」で変換すると、「1 コマ目と同じにする範囲」の下に「ドットを直す」の欄が出ます（コマが 12 倍で出ます）
2. 色見本をクリックして色を選び、**左ドラッグで塗る**。**右クリックで透明**にする。**Alt＋クリックで絵の色を拾う**
3. 「,」「.」（または ◀ ▶）でコマを切り替える。**O** で前のコマを薄く重ねると、ちらつく所が見つけやすい
4. 間違えたら **Ctrl＋Z**（やり直しは Ctrl＋Y）。横の小さな再生の見本ですぐ確かめられます
5. そのまま「④ スプライトシートを保存」などで保存すると、直しが入っています（JSON・GIF・左右反転・.piskel も）

- 使える色はシートのパレットだけです（新しい色は作れません）
- 直しは**元のコマ**に入るので、順番 1,2,3,2 の 2 番目と 4 番目は 1 回直せば両方変わります（Piskel のように 2 回直さなくてよい）
- 「1 コマ目と同じにする範囲」や色数などを後から変えても、直しはその上に重ね直します。直したときと下の色が変わったドットは橙の枠で知らせます
- 「直しの一覧を保存（JSON）」で直しだけを保存できます（`<出力名>_<名前>_edits.json`）。次に開いたときに「直しの一覧を読み込む」で戻せ、
  CLI の `--edits` でも同じ直しを当てられます
- 変換し直してコマの大きさなどが変わり、直しを当てられないときは確認が出ます。「直しを保存してから捨てる」（おすすめ）、「保存せずに捨てる」、
  「やめる」（変換し直しを取り消して、前の結果・直し・設定の値に戻す）から選びます
- アプリ内で直した後に、さらに Piskel で大きく直すこともできます（下の ① の .piskel に直しが入っています）

## Piskel で直す

流れ: **① Sprite App で保存 → ② Piskel で開く → ③ 直す → ④ Piskel で保存 → ⑤ Sprite App で読み戻す**

いちばん簡単なのは **.piskel ファイル**でやり取りする方法です（コマの大きさや数を入れなくてよく、格子状になる心配もありません）。

## ① Sprite App で保存するもの

ブラウザ版（`apps/sprite/web/sprite-app.html`）で「コマが並んだ絵」を変換したら、「コマの再生と保存」の欄で次を**同じフォルダ**に保存します。

| ボタン | ファイルの例 | 使い道 |
| --- | --- | --- |
| **Piskel で直す用（.piskel）を保存** | `ai08_sprite_frames_66x92_4f.piskel` | Piskel で開いて直すもの |
| **⑤ シートの情報を保存（JSON）** | `ai08_sprite_frames_66x92_4f.json` | コマごとの時間・順番・足元の位置。**直した後も捨てない**（Piskel には時間が入らないため） |
| ④ スプライトシートを保存（PNG） | `ai08_sprite_frames_66x92_4f.png` | 直す前のシート。読み戻すときに選ぶと、直したドットに印を付けた画像も作れます（なくても大丈夫） |

ファイル名の `66x92` は **1 コマの幅 × 高さ**（ドット）、`4f` は**コマの数**です。

ちらつきの見える化（PNG）も保存しておくと、直す場所の目印になります（上の方で 1 コマ目と違うドットを赤紫の枠で囲んだ画像。
全部が間違いではありません。腕や髪は動くので違って当然です）。
変換するときに「ちらつきを減らす」を「あり」にしておくと、小さな点や短い線の違いは先に 1 コマ目の色に戻るので、直す所が少し減ります
（大きな違いは残ります）。
頭をコマごとに描き直したちらつき（頭の輪郭・髪の束のずれ）は、「コマの再生と保存」の「**1 コマ目と同じにする範囲**」で、1 コマ目の上を
マウスでドラッグして頭を囲むと、2 コマ目以降の頭が 1 コマ目と同じになります（CLI の `--same-as-first x,y,幅,高さ`）。
写せなかったコマは理由が表に出るので、範囲を少し大きく・小さくして試してから Piskel で直すと、直す所がぐっと減ります。

## ② Piskel で開く

1. https://www.piskelapp.com/ を開き、「**Create Sprite**」を押す
2. 右側の縦に並んだアイコンのうち「**Import**」を押す
3. 「**Load .piskel file**」の「**Browse .piskel files**」を押し、① の `.piskel` を選ぶ
4. いま開いている絵を置き換えるか聞かれたら、置き換える
5. 下のコマの一覧にコマが並び、右上の小さなプレビューで動けば成功です（速さも入っています）

> Piskel の速さは「1 秒あたりのコマ数」1 つだけです。コマごとの時間がいちばん多い値から決めてあります（例 150 ミリ秒 → 7 FPS。
> 約 143 ミリ秒で再生されるので少しだけ速く見えます）。本当の時間は JSON に残っていて、読み戻すときはそちらを使います。

<details><summary>PNG のシートを使うとき（.piskel を使わない方法）</summary>

1. 「**Import**」→「**Import From Picture**」の「**Browse images**」で、④ のシート（`…_66x92_4f.png`）を選ぶ
2. 「**Import as spritesheet**」を選び、**Frame size** の幅と高さに、ファイル名の数（例 `66` と `92`）を入れる。Offset は 0 のまま
3. 先に進んで読み込む。下のコマの一覧に 4 コマ並べば成功

うまく切れないとき（コマの途中で切れる・コマの数が違う）は、幅・高さの数が違っています。
**透明だけのコマがあると、Piskel はそのコマを読み込みません**（コマがずれます）。
</details>

## ③ 直す

- 左の道具の「**スポイト**」（Color picker）で、絵の中の色をクリックして拾う → 「**ペン**」で 1 ドットずつ塗る。
  **新しい色を作らず、絵の中にある色だけを使う**と、パレットがそろったままになります（違う色を使うと、読み戻しで知らせます）
- 拡大はマウスのホイール。間違えたら Ctrl+Z
- コマを切り替えるのは下のコマの一覧。前のコマを薄く重ねて表示する「Onion skin」を使うと、ちらつきが見つけやすい
- **コマの大きさ（キャンバスの大きさ・Resize）は変えない**。変えると読み戻せません
- **コマを足したり消したり、並べ替えたりしない**（JSON のコマの数・時間・順番と合わなくなります）。順番を変えたいときは Sprite App の「順番」で作り直します
- **同じコマを 2 回使う順番**（1,2,3,2 など）のシートは、再生する順に 1 コマずつ並んでいます（4 コマ）。
  2 コマ目と 4 コマ目は同じ絵なので、**片方を直したら、もう片方も同じに直してください**。違っていると読み戻しで知らせます
  （「同じコマは先に出てくるコマに合わせる」を選ぶと、2 コマ目の直しを 4 コマ目にも使えます）
- レイヤーを足してもかまいません（読み戻すときに、見えるレイヤーを重ねて 1 枚にします）。半透明のペンは使わないでください

## ④ Piskel で保存する

**.piskel で保存（おすすめ）**: 右側のアイコンの「**Save**」を押し、「**Save offline as File**」を押す。`<名前>-<日時>.piskel` がダウンロードされます。
名前はそのままでかまいません（読み戻しでは JSON から名前を決めます）。

<details><summary>PNG で書き出すとき</summary>

1. 右側のアイコンの「**Export**」を押し、「**PNG**」を選ぶ
2. Scale（大きさ）は **1 倍**のまま
3. 「Download」で保存。Columns（列の数）はいくつでもかまいません（格子状でも、読み戻しで 1 コマの大きさから読みます）
</details>

## ⑤ Sprite App で読み戻す

ブラウザ版のいちばん下の「**直したシートを読み戻す**」の欄で、ファイルを選ぶだけです（ページを開いて準備ができてから）。

1. 「**A. 直したファイル（.piskel か PNG）**」で、④ で保存したファイルを選ぶ
2. 「**B. 元のシートの情報（JSON）**」で、① の ⑤ で保存した JSON を選ぶ
3. （なくてもよい）「**C. 直す前のシート（PNG）**」で、① の ④ のシートを選ぶ
4. すぐに確かめた結果と、作り直した動きの再生が出ます。黄色の「確かめてほしいこと」があれば読みます
   - **元のパレットに無い色**: 確認の画像の赤紫の枠。そのまま使います。直したいときは Piskel で直すか、「おかしな色を直す」に印を付ける（いちばん近い元の色にします）
   - **半透明のドット**: 確認の画像の橙の枠
   - **同じコマなのに違う**（2 コマ目と 4 コマ目など）: 確認の画像の青い枠
   - 作り直せないとき（コマの大きさ・数が違う、透明だけのコマがある）は、赤い枠で理由が出ます
5. 下のボタンで保存します

| ボタン | ファイルの例 | 使い道 |
| --- | --- | --- |
| 横 1 列に並べ直したシート（PNG） | `ai08_sprite_frames_66x92_4f_edited.png` | ゲームで使うシート |
| シートの情報（JSON） | `…_edited.json` | 時間・順番・足元は元の JSON のまま。PNG と 2 つで 1 組 |
| GIF | `…_edited.gif` | 人に見せる用（拡大は「GIF の拡大」で選ぶ） |
| 続けて直す用（.piskel） | `…_edited.piskel` | もう一度 Piskel で直すとき（② から） |
| 左右反転のシート・情報・GIF・.piskel | `ai08_sprite_frames_mirror_66x92_4f_edited.png` など | 反対の向きに歩かせるとき |
| 確認の画像・記録 | `…_edited_check.png` / `.json` | 新しい色・半透明などの場所 |
| 直したドットの印（PNG） | `…_edited_changes.png` | C を選んだときだけ。上の段が直す前、下の段が直した後で、違うドットを赤紫の枠で囲んだもの |

CLI では同じものを次のように作れます（中身はバイト単位で同じ）:

```bash
python -m apps.sprite 直した.piskel --readback ai08_sprite_frames_66x92_4f.json --original ai08_sprite_frames_66x92_4f.png --gif --mirror --piskel
```
