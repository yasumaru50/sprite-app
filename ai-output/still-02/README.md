# still-02: ざらついた範囲を模様に整える（`--tidy-pattern`）

入力は `ai-input/ai17_room_fine.png`・`ai-input/ai18_station_fine.png`（1586×992）。どちらも `--width 600`（600×375 ドット、16 色）。
作り方: `python tools/compare_still_pattern.py <入力> --width 600 --out <名前> [--crop 40,215,240,375]`。
PNG・JSON は `python -m apps.still <入力> --width 600 --tidy-pattern` の出力そのもの。

| ファイル | 中身 |
| --- | --- |
| still-02_ai17_wall.png | ai17 の壁・畳・座布団のあたり（ドットの 40,215〜240,375）。左が整える前、右が整えた後（4 倍） |
| still-02_ai17_overview.png | ai17 の全体。左が整えた後、右が整えた範囲を色で重ねたもの（2 倍。色は範囲ごとに変えているだけ） |
| still-02_ai18_overview.png | ai18 で同じもの |

| 絵 | 整えた範囲 | 変えたドット | 3 色目が多くて整えなかった範囲 | 輪郭として守ったドット |
| --- | --- | --- | --- | --- |
| ai17 | 82 | 34,543（全体の 15%） | 18 | 10,352 |
| ai18 | 56 | 19,436（全体の 9%） | 39 | 1,211 |

感想:
- ai17: 壁は「オリーブ色に明るい点 25%」のそろった網目に、畳も 2 色の網目になった。座布団・棚の戸・机の上・窓の外の空・照明の障子もそろった。
  輪郭（黒）はそのまま。壁の上の方の暗い所に、範囲から外れた元の点が少し残る
- ai17 で巻き込まれてほしくなかった所: カーテンはほとんど残ったが、右上の一部（青と白の柄）が 1 か所だけ整えられた
- ai18: 空・雲の縁・ホームの地面の木もれ日の影・ひさしの下の板が整った。山の木の一部と、右下の石垣の一部も整えられた（2 色が大半でざらついて見えるため）
- 3 色目の決まり: 案のまま（3 色目が 1 割以上なら整えない）では、ai17 の壁（3 色目 10.1〜11.9%。暗い点が 1〜2 ドットずつ散らばる）が外れたので、
  3〜63 ドットのかたまりだけを数えるようにした
