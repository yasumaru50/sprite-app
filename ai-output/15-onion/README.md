# 15-onion（「ドットを直す」の「重ねるコマ」）

条件: 幅 1200px、「コマが並んだ絵」で ai-input/ai07.png（歩き 4 コマ）を変換し、「ドットを直す」で 3 コマ目を開いて拡大 8 倍、「前のコマを薄く重ねる」を入にした画面。

| ファイル | 重ねるコマ |
| --- | --- |
| 1_prev1.png | 1 つ前（2 コマ目。今までと同じ） |
| 2_prev2.png | 2 つ前（1 コマ目） |

感想: 1 つ前（2 コマ目）は足・しっぽの位置が違うので、薄い影がしっぽの下・足元・頭の後ろに広くはみ出す。
2 つ前（1 コマ目）は足の形が近く、しっぽ・足元の影はほとんど重なる（はみ出すのは主に体の右の縁の 1〜2 ドット）。足元のちらつきを探すなら 2 つ前のほうが見やすい。
