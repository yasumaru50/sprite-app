# 16-compare（大きさをくらべる）

条件: ai-input の画像を既定の設定で変換し（ai07 は `--frames --frame-count 4`）、`python -m apps.sprite compare`（既定: 4 倍・マス目 16 ドット・間 8 ドット）で並べた。
基準のキャラ（1 枚目）は、指示の ai06 が ai-input に無いので、同じ立ち絵の ai04（どんぐりの剣士）にした。

| ファイル | 並べたもの |
| --- | --- |
| 1_compare.png | ai04（基準）・ai03（キノコ）・ai05（スライム）・ai07（歩きのシート＋JSON の 1 コマ目） |
| 2_compare_japanese_name.png | 同じもので、ai03 を「きのこ.png」にしたもの（画像の中では「#2」。CLI は「#2 = きのこ」と表示） |

大きさ（切り詰めた後のドット）: ai04 34x44、ai03 49x45、ai05 31x20、ai07 の 1 コマ目 52x91。

感想: ai04・ai03・ai05 は線の太さ（1 ドット）と頭身がそろって見えるが、ai07 は高さが ai04 の約 2 倍（91 / 44）で、
同じ画面に並べると明らかに大きい（青い点線 = ai04 の頭の高さは、ai07 の胸のあたり）。ai07 は格子が細かく検出されているので、
ほかの素材と並べて使うなら半分くらいの大きさで作り直すとそろう。2 枚目は「#2」の文字が短くなるが、キノコの絵の幅の方が広いので、画像の大きさは 1 枚目と同じ（960x508 画素）。
