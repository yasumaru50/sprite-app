# 13-polish（仕上げ: 画面の説明文）

「説明をすべて表示」を押した状態の、直す前（`*_before.png`）と後（`*_after.png`）。合成の画面（画像は選んでいない）。動き・出力は変えていない。

- `save_*`: 保存の欄。ZIP の説明に「③ の PNG」と、入らない確かめ用のファイルとその保存場所を足した。「1 つずつ保存」の見出しの横を「今までの保存のボタン」→「ファイルを 1 つずつ保存するボタン（③〜⑨・エフェクト・しゃべり）」
- `motion_*`: 動きの説明。「なし」のとき「今までどおり 1 枚の PNG」→「変換結果の 1 枚の PNG（③）」
- `readback_*`: 読み戻しの B の説明。「⑤ シートの情報を保存（JSON）のファイル」→「シートと一緒に保存した JSON（ZIP の中か、1 つずつ保存の ⑤）」

感想: 文の直しだけなので見た目の大きさはほとんど同じ。保存の欄の説明は 1 行ほど長くなった。
