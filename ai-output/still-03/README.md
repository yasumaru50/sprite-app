# still-03: 今風モード（`--mode modern`）と孤立したドットをそろえる（`--tidy-dots`）

入力は `ai-input/ai15_room.png`（グリッド検出、165×95 ドット）と `ai-input/ai17_room_fine.png`（`--width 600`、600×375 ドット）。
PNG・JSON は `python -m apps.still` の出力そのもの。

| ファイル | 作り方 |
| --- | --- |
| still-03_<絵>_98.png | `--mode pc98`（16 色・4096 色に丸める） |
| still-03_<絵>_modern32.png | `--mode modern`（32 色・丸めない・似た色をまとめる） |
| still-03_<絵>_modern32_tidy-dots.png | `--mode modern --tidy-dots` |
| still-03_<絵>_tidy-dots_overlay.png | 上の結果に、置き換えたドットを濃い桃色（まわり 1 ドットは薄い桃色）で重ねたもの（ai15 は 4 倍、ai17 は 2 倍） |

| 絵 | 今風の色数 | まとめた色 | 置き換えたドット |
| --- | --- | --- | --- |
| ai15 | 29（上限 32） | 3 組（19・36・10 ドットの色。距離 0.028〜0.039） | 6 |
| ai17 | 32 | 0（いちばん近い組でも 0.045） | 1,409（全体の 0.6%） |

感想:
- 今風は 98 より空の夕焼けのグラデーション・壁の色の段がなめらかになり、98 の雰囲気から離れた「今の」見た目になった
- ai15 でまとまったのは、暗い紺と暗い灰青・暗い茶と暗い緑・オレンジの 2 色の、少ないドットの色だけ。見た目はほとんど変わらない
- ai17 は 0.04 より近い色が無く、何もまとまらなかった。にじみの色は境目の中間の色で、隣の色と近いとは限らないため（TODO に記録）
- `--tidy-dots` は ai17 で壁・空・障子に散らばった浮いた点を消した。輪郭（いちばん暗い色）と端は変えていない。ai15 はもともと点が少なく 6 ドットだけ
