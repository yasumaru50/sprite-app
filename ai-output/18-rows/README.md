# 18-rows: 縦にも並んだ絵の切り分け

入力: `ai-input/ai21_spin12.png`（12 コマの回転、3 段 × 4 列、緑の背景、1536×1024）と `ai-input/ai07.png`。画面はヘッドレスの Chromium で操作した。

| ファイル | 中身 |
| --- | --- |
| `1_ai21_boxes.png` | ai21 をドットの大きさ 6.5 で変換したときの元の画像。赤い枠が 12 個（番号は左から右、上の段から下の段） |
| `2_ai21_dot6.5_sheet.png`（`_x4` は 4 倍）・`.json` | 6.5 で変換した 12 コマのシート（画面で保存。CLI の `--frames --dot-size 6.5` とバイト単位で同じ） |
| `3_ai07_sheet.png`（`_x4` は 4 倍）・`.json` | ai07 を画面で変換したシート。main の CLI の出力とハッシュが同じ（PNG `eadf2c6e…`） |

## 数

- ai21: 12 コマ、1 コマ 47×51 ドット（前は 4 コマ、47×157）。キャラの高さ（コマの順）49・50・49・51・50・49・50・49・50・47・51・51（差 4）
- ドットの大きさの欄が空のときの候補: 前は「段ごとの高さ」（4 コマ × 3 段）だったのが、コマ 12 個の高さになった
  （5: 差 5、5.5〜7: 差 4、12: 25〜28 で差 3。12 は体が半分の高さになるので、差だけでは選べない）
- 1 段の絵（ai07・ai08・ai09・ai13・ai14、1 枚の絵の ai04・ai05、つなげる ai07+ai09、まとめる ai07+ai13）は、main の CLI の出力 47 ファイルとハッシュが同じ

感想: 段に分けたので、1 コマに 1 体ずつ入り、回転のアニメとして使える。同じ形のコマの高さの差は 4 ドットで、前の段ごとの高さと同じ。
