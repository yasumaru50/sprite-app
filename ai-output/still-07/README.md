感想:
- photo01: 縦長の写真から廊下の真ん中の帯が残る。50,50 は手前の床の比率が多く、50,20 は崩れた天井と奥の廊下が入って、背景としてはこちらの方が絵になる
- ai15: 切り抜く前と後で、残ったマスの色は 100% 同じ（PNG の画素を比べた）。マスの境目も切り抜く前の境目の一部で、格子はずれていない
- ai17_room_fine は今のグリッド検出でマス目が見つからない（still-03 と同じ）ので、マス目を探す比較は ai15_room で作り、ai17 は `--width 600` で入力の段階の切り抜きにした
- photo03: もとが 16:9 なので左右を 192px ずつ切って 640×400。右の五重塔の端が少し切れる（残したいときは `--anchor 100,50`）。空の網目（2×2）は still-06 と同じように入る

ブラウザ版: PNG に直した photo01（612×816。写真の下書き・16:9・50,20）と ai15（今風・数値で 16:9・50,0）で、CLI とバイト単位で同じだった。
