# still-06: 1 枚絵のアプリに「ディザを作る」（`--dither 2x2`・`4x4`）

なめらかに色が変わる所（空など）で、減色で分かれた隣り合う 2 色の間を、決まった網目（Bayer 型）でつなぐ。パレット（選ばれる色）はディザなしのときと同じ。
入力は `ai-input/photo03.JPG`（富士山と五重塔の写真、3840×2160）。PNG・JSON は `retrocore.still.convert.convert_still_bytes()` の出力そのもの（CLI と同じ）。
写真の下書きの初めの設定は、この版から「似た色をまとめる」が切（下の結果はどれも切）。

| ファイル | 作り方 |
| --- | --- |
| still-06_photo03_w640_16c_4bit_off.png | `--mode photo --width 640 --colors 16 --4bit`（ディザなし） |
| still-06_photo03_w640_16c_4bit_2x2.png | 同じ ＋ `--dither 2x2` |
| still-06_photo03_w640_16c_4bit_2x2_overlay.png | 上の 2x2 に「網目を入れたドットを色で重ねる」を重ねたもの（濃い緑: 網目で色を変えたドット、薄い緑: 網目の範囲） |
| still-06_w640_compare.png | 上の off（左）と 2x2（右）を 2 倍で並べたもの |
| still-06_w640_compare_crop.png | 左上の空（0,0〜220,130）を 4 倍で並べたもの（左 off、右 2x2） |
| still-06_photo03_w1280_32c_off.png | `--mode photo --width 1280`（32 色・ディザなし） |
| still-06_photo03_w1280_32c_4x4.png | 同じ ＋ `--dither 4x4` |
| still-06_w1280_compare_crop.png | 左上の空（0,0〜440,260）を 2 倍で並べたもの（左 off、右 4x4） |

| 結果 | 大きさ | 色数 | 網目で色を変えたドット | 網目の範囲 | 2 色の組 | 孤立したドットを置き換えた数 |
| --- | --- | --- | --- | --- | --- | --- |
| w640 16 色 4096 色 off | 640×360 | 16 | - | - | - | 175 |
| w640 16 色 4096 色 2x2 | 640×360 | 16 | 27,337（12%） | 87,352（38%） | 20 | 163 |
| w1280 32 色 off | 1280×720 | 32 | - | - | - | 1,182 |
| w1280 32 色 4x4 | 1280×720 | 32 | 119,345（13%） | 490,092（53%） | 110 | 1,001 |

感想:
- w640＋2x2: 空の大きな段（左上・右上の暗い雲、地平線の近くの明るい帯）が、25・50・75% の網目の段でつながり、98 の取り込み画像のような見た目になった。
  木の葉・五重塔の輪郭・富士山の雪の縁には入らない。五重塔の壁や手前の暗い所にも少し入る（そこも色がなめらかに変わっているため）
- w1280＋4x4: 17 段なので段の境目がほとんど見えず、空がなめらかなグラデーションになる。32 色では空の近い色が多く、組（110）も範囲（53%）も多い。
  拡大しないと網目は細かい点にしか見えない
- 似た色をまとめる 入（前の写真の下書きの既定）では w640 16 色が 12 色に減り、空の段が粗くなる（この版から写真の下書きの既定は切）

時間（CLI・このコンテナ）: w640 約 6 秒、w1280 約 11 秒（ディザの分は 1〜2 秒）。ブラウザ版で w640＋2x2 は 7.8 秒。
注意: photo03 は JPEG なので、ブラウザ版では少し違う結果になる（JPEG を画素に戻すライブラリの違い）。PNG にした入力では、ブラウザ版と CLI でバイト単位で同じだった。
