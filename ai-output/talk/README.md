# 口パク（しゃべりのシート）

ai04（目を開けた 1 枚の絵）の呼吸に、まばたきと口パクを入れた「しゃべりのシート」。口と目は簡単に描いた（口 = 輪郭の色の 3×2 の四角、
真ん中の下 1 ドットは頬の色。半分の口 = 上の行だけ。目 = 目の上の行を肌の色にした）。差し替えの一覧は同じフォルダの `*_swaps.json`。

```bash
python -m apps.sprite ai04.png --motion breathe --gif --gif-scale 8 --swaps ai04_breathe_swaps.json
```

| ファイル | 設定 | 結果 |
| --- | --- | --- |
| ai04_breathe_talk_8x.gif | 呼吸（500 ミリ秒 × 2）＋まばたき（閉じた目・半分閉じた目）＋口（開いた口だけ） | 動き 3 周・27 フレーム・横 918 ドット・3000 ミリ秒。口は 閉じる → 開く を 150 ミリ秒ごと（20 回）。まばたきは 1500 ミリ秒から |
| ai04_breathe_talk_half_8x.gif | 同じ＋半分開いた口 | 動き 4 周・43 フレーム・横 1462 ドット・4000 ミリ秒（3000 は口の 1 回り 400 で割り切れないため）。閉じる → 半分 → 開く → 半分 を 100 ミリ秒ごと（40 回）。まばたきは 2000 ミリ秒から |
| talk_screen.png | 画面で「描く絵: 開いた口」を選び、口を描き直したところ（2 倍） | 絵の下に「しゃべりのシート（口パク）」の再生と保存のボタン。画面で保存したシート・JSON・GIF は CLI とバイト単位で同じ |

数: 口の合い方は 1 コマ目 1.0・2 コマ目 0.927（2 コマ目の位置は呼吸のずれ込みで同じ所。ずれ 0,0）。まばたきは両方 1.0。入らないコマ・目と口の重なりは無し。

感想: 呼吸で顔が 1 ドット下がっても口は顔からずれず、口と目が同じフレームで動いても自然に見える。半分の口ありの方が、しゃべっているように見える。
最初は口のまわり 2 ドットで位置を探していて、肌だけの所なので 2 コマ目の口が 1 ドット右にずれた（口だけ 4 ドットに広げて直した）。
目は簡単に描いたので形が左右で少し違う（仕組みの問題ではない）。
